\## 🇷🇺 Русский



Кастомный графический лаунчер уровня AAA для запуска нативного PC-порта Tekken 3 Expanded. Этот скрипт полностью заменяет стандартную оболочку игры на стильный чёрно-синий неоновый интерфейс.



\### 🌟 Особенности:

\* \*\*Премиальный дизайн:\*\* Тёмная тема с неоновыми синими линиями и шрифтом Impact.

\* \*\*Мультиязычность:\*\* Полная встроенная локализация интерфейса (Русский, Английский, Испанский) с переключением кнопкой на главном экране.

\* \*\*Сетка блоков:\*\* Удобное разделение интерфейса на карточки Игроков, Диска и Карт памяти.



\### 🛠️ Как запустить игру через этот лаунчер:

1\. Скачайте файлы этого репозитория (`tekken\_launcher.py`).

2\. Поместите их в корневую папку проекта Tekken 3 Expanded (туда, где вы компилировали игру через `Setup Tekken 3.cmd`).

3\. Вместо старого лаунчера запустите этот файл через терминал: `python tekken\_launcher.py`.

4\. В правом верхнем углу выберите нужный язык, нажмите большую синюю кнопку \*\*ЗАПУСТИТЬ ИГРУ (PLAY)\*\*, и лаунчер откроет игру напрямую в обход стандартного меню.

\## 🇬🇧 English



A premium custom graphical launcher built with Python and CustomTkinter for the Tekken 3 Expanded native PC port. This script completely replaces the standard configuration menu with a sleek cyberpunk-style interface.



\### 🌟 Features:

\* \*\*AAA-Grade UI:\*\* High-budget dark theme with neon blue grids and vector gamepad styling.

\* \*\*Tri-language Support:\*\* Instant dynamic translation between English, Russian, and Spanish via the top corner toggle.

\* \*\*Clean Layout:\*\* Organized modular frames for Player setups, Disc status, and Memory Cards.



\### 🛠️ How to run:

1\. Download the files from this repository (`tekken\_launcher.py`).

2\. Drop them directly into the root folder of your compiled Tekken 3 Expanded project (where your build release folder is located).

3\. Instead of using the default executable launcher, run this script via command line: `python tekken\_launcher.py`.

4\. Click the large blue \*\*PLAY\*\* button to launch the native game engine directly with flawless 60 FPS!
